# 내 주식 비서

토스증권이 모아주는 종목 뉴스를 AI가 읽고 호재·악재를 판단해서
텔레그램으로 알려주고, 웹 대시보드로 정리해 보여주는 개인용 도구입니다.

**대시보드 → [여기서 보기](../../deployments/github-pages)** (Settings → Pages 설정 후 주소가 생깁니다)

## 뭘 하나요

| 기능 | 설명 |
|---|---|
| 아침 브리핑 | 평일 아침, 밤사이 등락·중요 뉴스·오늘의 신호를 한 통으로 |
| 급등락 알림 | 장중 30분마다 확인해 ±5% 넘게 움직이면 즉시 알림 |
| 주간 성적표 | 일요일마다 한 주 요약과 판정 적중률 복기 |
| 종합 점수 | 뉴스·차트·실적·관심도 네 팀 점수를 합쳐 100점 만점으로 |
| 불리 vs 베어 토론 | 의견이 갈리는 종목을 두고 AI 둘이 근거를 주고받고 판정 |
| 적중률 채점 | "호재"라고 본 뉴스가 다음날 실제로 올랐는지 자동 채점 |

## 데이터 출처

차트·뉴스·커뮤니티는 토스증권, 재무지표는 네이버증권, 실적 일정은 나스닥에서 가져옵니다.
분석은 Claude(Anthropic API)가 합니다.

## 구조

```
news_alert.py    분석·알림 본체
index.html       웹 대시보드 (GitHub Pages로 서비스)
feed.js          대시보드가 읽는 분석 결과
.github/workflows/   자동 실행 (브리핑·급등락·주간)
```

비밀키는 저장소에 없습니다. GitHub Secrets에만 보관하며,
로컬 설정 파일(`config.json`)은 `.gitignore`로 제외됩니다.

## 주의

여기 나오는 점수·신호·토론은 **AI가 정리한 참고 자료**입니다.
투자 조언이 아니며, 투자 판단과 그 결과에 대한 책임은 이용자 본인에게 있습니다.
